# Online Project Management Tool

## Team Name
CodeCrew

## Project Description

The Online Project Management Tool is a Java-based GUI application
designed to help organizations manage users, projects, tasks and
project progress in one system.

The system provides separate access for three roles:

- Admin
- Project Manager
- Team Member

## Main Features

- User Management
- Project Management

- Task Tracking
- Project Progress Monitoring
- Role-Based Dashboards
- Database Connectivity

## User Roles

### Admin
- Manage users
- Manage projects
- Manage system settings

### Project Manager
- Create and manage projects
- Assign tasks
- Monitor project progress
- View reports

### Team Member
- View assigned tasks
- Update task status
- View project details
- Manage profile
